# Included license texts

- `LGPL-3.0-only.txt` applies to the Qt for Python components when distributed
  under their LGPL option. It also contains the incorporated GPLv3 terms.
- `Python-3.11.txt` covers the bundled CPython runtime and its included notices.
- `BSD-2-Clause-xxHash.txt` covers python-xxhash and xxHash.

The application and the bundled GPL-3.0-or-later decoder are covered by the
top-level `LICENSE` file. Package names and upstream links are listed in
`THIRD_PARTY_NOTICES.md`.

The Windows release preparation script adds the applicable Qt license texts under
`LICENSES/Qt` and generates detailed Qt and PySide third-party attribution reports.
